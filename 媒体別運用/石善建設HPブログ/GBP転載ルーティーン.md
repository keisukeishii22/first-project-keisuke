# HPブログ → GBP投稿 転載ルーティーン

石善建設 HP(https://ishizenkensetsu.com/)のブログ記事を、Googleビジネスプロフィール(GBP)の「最新情報」投稿用に要約する定常運用の手順。

- **運用開始**:2026-08-17
- **投稿ペース**:3日に1投稿(圭佑が手動投稿)
- **生成物の保存先**:`生成物/GBP投稿/`
- **記録先**:`進捗メモ.md` の「媒体別生成ログ」

## なぜやるか

2026-07-24 の SEO/MEO アクションプラン §6 で、GBP の「週1回の最新情報投稿」が MEO の改善項目として挙がっている。地域工務店では検索順位以上に集客インパクトが大きい領域であり、3日に1投稿はこれを上回るペースになる。HP ブログの資産をそのまま再利用できるため、追加の取材コストはかからない。

## ルーティーンの中身

### 1. 未要約の記事を洗い出す

WordPress REST API で、最後に要約した記事より後に公開されたものを取得する。

```bash
curl -s "https://ishizenkensetsu.com/wp-json/wp/v2/posts?after=YYYY-MM-DDT00:00:00&per_page=50&orderby=date&order=asc&_fields=id,date,link,title,content"
```

- `after` には、`進捗メモ.md` の媒体別生成ログに記録した「要約済みの最終公開日」を入れる。
- HP は概ね3日おきに公開されている(2026年7〜8月実績)。前回から日が空いていれば複数本まとめて処理する。
- 0件なら「新着なし」と報告して終了。空振りの報告も記録に残す。

### 2. 1記事ずつ要約する

**GBP の投稿本文は1,500文字が上限。** 実運用では読み切ってもらえる 600〜800字を目標にする(上限いっぱいは使わない)。

構成テンプレート:

```
【冒頭2行】結論＋地域名。GBPのプレビューで見えるのはここだけなので、
          この2行で内容が伝わるようにする。

【本文】箇条書き中心。スマホの流し読みを前提に、
        「サイン5つ」「ポイント7つ」のように数を示して並べる。

【費用・制度】元記事に書かれている数字のみを引用する。

【自社の一言】創業1946年/職人の手仕事/正直に、といった姿勢を1〜2文。

対応エリア:袖ヶ浦市・木更津市・君津市・富津市

▼(記事で読める内容を3点)はこちら
https://ishizenkensetsu.com/(スラッグ)/
```

### 3. 保存とカレンダー

- 既存の `生成物/GBP投稿/HPブログ要約_2026-07-22以降.md` に追記する(四半期ごとにファイルを分ける)。
- 投稿カレンダーの末尾に、3日間隔で新しい行を足す。
- **並び順は季節・時事で最適化してよい**。防災の日(9/1)に耐震、台風期に塩害、お盆・年末年始の帰省期に空き家と二世帯、冬前に内窓と結露、といった配置が効く。記事はいずれも通年で通用する内容のため、HP の公開順に縛られる必要はない。

### 4. 記録・コミット・報告

1. `進捗メモ.md` の「媒体別生成ログ」に、生成日・対象記事・要約済みの最終公開日を追記する。
2. そのセッションの作業ブランチにコミット&プッシュする。
3. 圭佑に、生成本数・各投稿の文字数・投稿カレンダー・投稿前に確認が必要な点を報告する。

## ガードレール(必ず守る)

`媒体別運用/石善建設HPブログ/ガードレール.md` と `情報源ガイドライン.md` に加えて、GBP 特有の注意点は次のとおり。

- **数字を新たに作らない。** 費用目安・制度の要件・統計は、すべて元記事に書かれているものだけを引用する。要約の過程で丸めたり盛ったりしない。
- **補助金・税制には時点表記を付ける。** 「先進的窓リノベ」「給湯省エネ」などは年度ごとに内容も予算枠も変わり、予算切れで受付終了になる。投稿前にその時点の受付状況を確認し、断定を避けて「お問い合わせ時点の情報でご案内します」の一文を添える。予算切れの制度を告知すると、問い合わせ時にトラブルになる。
- **HP 記事との重複表現をそのままコピーしない。** GBP と HP で完全に同一の文章が並ぶのは避け、要約・再構成した文章にする(元記事への送客が目的であり、GBP 単体で読ませきる必要はない)。
- **写真は現場が特定できないものに限る。** 12週テーママップ共通ルールの「現場写真禁止」に従い、外観・素材・完成写真など掲載許可の取れたものを使う。お施主様が特定できる要素は入れない。
- **取引先・契約内容の固有名詞は出さない。**
- **不動産に触れる回は宅建業法の広告規制に注意する。** 空き家・土地探しの回は `媒体別運用/圭佑不動産インスタ/ガードレール.md` の広告規制の項も併せて確認する。投資用物件の勧誘と受け取られる表現は使わない。
- **生成物は下書き。** 投稿は必ず圭佑の確認を経る。

## 起動方法

- 圭佑から「GBP投稿を作って」「HPブログの要約お願い」と言われたら、このルーティーンを実行する。
- 在庫が残り3本を切ったら、指示がなくても新着記事の有無を確認して補充する。
- スケジュール実行(Claude Code on the web の triggers)に載せる場合は、**週1回・日曜**で「新着記事があれば要約、なければ新着なしと報告」とするのが在庫ペースに合う(3日おきの投稿に対し、週1回の補充で在庫は増えも減りもしない)。
  - 注意:note×Instagram の週次ルーティーン(自動運用ルーティーン.md)とは別系統。同じ日曜に走らせる場合も、生成物の保存先とログ欄が分かれていることを確認する。
