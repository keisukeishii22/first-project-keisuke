## WordPress での作業手順

### ① プライバシーポリシーに追記(上記A)

1. `https://ishizenkensetsu.com/wp-admin/` にログイン
2. 左メニュー「固定ページ」→ 一覧から「プライバシーポリシー」を編集
3. 本文の末尾に、上記A の2見出し(アクセス解析ツール/アフィリエイトプログラム)を貼り付け
4. 「更新」

### ② 免責事項ページを新規作成(上記B)

1. 「固定ページ」→「新規固定ページを追加」
2. タイトル:`免責事項`、本文に上記B を貼り付け(URL スラッグは `disclaimer` 推奨)
3. 「公開」
4. フッターメニューに表示:「外観」→「メニュー」→ 該当メニューに固定ページ「免責事項」を追加 →「メニューを保存」
   (プライバシーポリシーと並べてフッターに置くと、審査担当が見つけやすい)

### ③ コラムに「お役立ちコラム」カテゴリを追加

1. 「投稿」→「カテゴリー」
2. 「新規カテゴリーを追加」:名前 `お役立ちコラム`(スラッグ `column` など)→「新規カテゴリーを追加」
3. 既存記事に割り当て:「投稿」→「投稿一覧」→ 記事にチェック →「一括操作」の「編集」→「適用」→ カテゴリーにチェック →「更新」
   (1件ずつなら各記事の編集画面 右側「カテゴリー」で付け替え)
4. 「未分類」を減らす:各記事を新カテゴリーに付け替える。今後の初期値を変えたい場合は「設定」→「投稿設定」→「投稿用カテゴリーの初期設定」を変更

### 審査申請時のチェックリスト

- [ ] プライバシーポリシーにアクセス解析・アフィリエイトの記載を追記した
- [ ] 免責事項ページを作成し、フッターから辿れるようにした
- [ ] コラム(/news/)に記事が複数あり、更新されている(現状10件以上=OK)
- [ ] 申請フォームの「サイトURL」は `https://ishizenkensetsu.com/`(または `/news/`)を指定
- [ ] 各コラム記事のアフィリ掲載時は冒頭に PR 表記(既存 note08/09 と同形式)
