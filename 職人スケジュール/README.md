# 職人スケジュール管理表

職人ごとの「今の仕事」「次の仕事」「そのあいだの空き日数」を1枚のブックで把握し、
次の受注を誰に割り当てるかを判断するための Excel ファイル。

- ファイル: `職人スケジュール管理表.xlsx`
- 元データ: アップロードされた「職人5人スケジュール3パターン」の **①シンプル型** シート
  （多田・松田・重田・原田・田中／一条(菅野様邸)・垣内邸・三栄港運(潮見)）を転記。
  ②③シートのサンプル（大工A〜E、A様邸〜O様邸）は実データではないため取り込んでいない。

## シート構成

| シート | 役割 | 入力 |
|---|---|---|
| 使い方 | 用語の定義・手順・アラートの意味 | — |
| ① 案件台帳 | **唯一の入力シート**。1行＝1職人×1案件 | 物件名・職人・工程・開始日・終了予定日・備考 |
| ② 職人ダッシュボード | 職人ごとの現在／次／空き日数を自動集計 | 職人名のみ（A列） |
| ③ 配置検討 | 次の仕事を誰に振るかを◎△×と推奨順位で判定 | 案件名・希望開始日・必要工期 |
| ④ 稼働カレンダー | 基準日から63日分の稼働(青)／空き(黄)マス目 | — |

## 計算の定義

| 項目 | 計算式 |
|---|---|
| 工期日数 | 終了予定日 − 開始日 + 1 |
| 経過日数 | 基準日 − 開始日 + 1 |
| 残り日数 | 終了予定日 − 基準日 |
| 空き開始日 | 稼働中: 今の現場の終了予定日 + 1 ／ 空き中: 直前に終わった現場の終了日 + 1 |
| 次の仕事までの空き日数 | 次回開始日 − 空き開始日（0＝連続、マイナス＝重複） |
| 本日以降の空き日数 | 次回開始日 − MAX(基準日, 空き開始日) |
| 推奨スコア | 期間重複なし=100点／要待機=60−待ち日数×2点 ＋ 空き日数（最大30点） |

基準日は `案件台帳!B3` の `=TODAY()`。日付を直接入力すれば将来時点のシミュレーションもできる。

## 元データで空欄だった項目（推測では埋めていない）

- 松田：一条（菅野様邸）の**開始日**が未入力
- 重田・田中：三栄港運（潮見）の**終了予定日**が未入力、前案件の物件名・開始日も未記載
- 多田・松田・原田：次案件の**物件名・終了予定日**が未入力（開始予定日のみ判明）

終了予定日が空欄の案件はカレンダーに表示されず、空き日数も確定しない。
案件台帳の「状況」列が「要確認（終了日未入力）」になっている行を埋めると全機能が揃う。
