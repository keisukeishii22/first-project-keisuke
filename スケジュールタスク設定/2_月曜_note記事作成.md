【毎週月曜:アフィリエイトnote記事の作成】

リポジトリの「アフィリエイトnote運用ルーティーン.md」の方針に従って、今週 note 投稿用の下書きを作成し、Google Drive の「記事本文」フォルダ(フォルダID: 1adhXBkqYQjVnJxH5GgDTV9TZ03MofUqD)に保存して報告する。このプロンプトの内容がリポジトリ内の文書と食い違う場合は、こちらを優先する。

■ 共通ルール
- 最初に Drive の「【圭佑さん記入】運用ステータス」(ファイルID: 1_XDBUat6hzSYenowPDwm978AxCzy27FOFM6enw0Ynic)を読み、note 公開済みの最新記事番号、実績の数字、「タスクへの追加指示」のうち note に関係するものを適用する。
- 次に Drive の「02_note記事(アフィリエイト)」ログフォルダ(フォルダID: 1YDsoZhS-sG4mf1H3__sYHoAoSvwJ5nk5)のログを読み、過去の作成記事・リライト履歴・未解決の裏取り事項を把握する。リライト履歴はリポジトリの表ではなく、このログを正とする。
- git へのコミット・プッシュはしない。記録は Drive のログだけに残す。
- 継続的な指示を受けても「次回から反映します」とだけ答えない。運用ステータスの「タスクへの追加指示」に書いてもらうよう案内する。

■ 本数
- 「記事本文」フォルダの最大記事番号 −(運用ステータスの note 公開済み最新番号)= 未公開本数。
- 未公開本数が10本以下:新規2本+リライト1本。
- 未公開本数が11本以上:新規1本+リライト1本。空いた分で、過去ログの「裏取りできなかった点」を公式サイトで再確認し、結果をログに書く。
- 新規にはメイン4市(袖ケ浦・木更津・君津・富津)の記事を1本以上含める。同じ記事を続けてリライトしない。

■ 裏取り
- 制度・法令・数字は、生成前に Web 検索に加えて公式サイトのページを実際に開いて確認する(各市・千葉県・国交省・国民生活センター・e-Gov などは接続を許可済み)。
- 公式ページで確認できた項目と、二次情報しか無い項目を分けて報告する。二次情報だけの数字は本文で断定せず「公式サイトで確認」と注記する。接続できなかったサイトがあれば、ホスト名を報告する。

■ 内部リンク(2026-11-10 圭佑さん指示)
- 新規・リライトとも、関連する公開済みの note 記事を1〜2本選び、本文の流れの中で「こちらの記事もどうぞ」の形でリンクを入れる(末尾にまとめるだけにしない)。
- リンク先は note 公開済み(運用ステータスの最新番号以下)の記事に限る。URL は、運用ステータスに書かれた note の URL、または Web 検索で実在を確認できたものだけを使う。確認できない場合は URL を作らず、「【内部リンク:note記事NN『タイトル』の公開URLを貼る】」と書いて圭佑さんが貼れるようにする。
- 関連する公開済み記事が見当たらない場合は無理に入れず、その旨を報告する。

■ ログと報告
- 「02_note記事(アフィリエイト)」フォルダに「ログ_YYYY-MM-DD_内容」を1ファイル新規作成する。内容:作成した記事の番号・タイトル・主な地域・テーマ・Drive リンク、リライト履歴(記事番号と主な変更)、入れた内部リンク、公式で確認できた点とできなかった点、未公開本数。
- 最後に、作成した記事のタイトルと Drive リンク、裏取りできなかった点、エピソードを入れた箇所、内部リンクで URL 未確定の箇所を報告する。
