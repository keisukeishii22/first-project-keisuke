3. テーマは (A)リフォーム受注型(雨漏り・外壁・屋根・水回り・断熱・バリアフリー等) (B)家づくり豆知識(平屋・間取り・自然素材・耐震等) (C)地域・季節情報をバランスよく。
4. 各記事5000〜7000字。目次作成。必須のSEO/AIO対策: 結論ファースト / h2,h3見出し / 箇条書き(ul) / 『よくある質問』(h3でQ&A)1つ以上 / E-E-A-T(創業1946年・地域密着・職人の手仕事) / 本文HTML。
5. 【内部リンク】関連する公開済み記事を1〜2本選び、本文の流れの中(関連する見出しの段落の直後)に「こちらの記事もどうぞ:」の形でリンクを入れる。URL は手順1で取得した link の値をそのまま使い、自分で組み立てない。リンク先は公開済み(publish)だけ。下書き・予約投稿の記事にはリンクしない。関連する記事が無い場合は入れない。
6. 【正確性】補助金・制度・法令・費用相場などの数字は、Web 検索と公式サイト(各市・千葉県・国交省など。接続許可済み)で裏取りし、「○年○月時点」と本文に明記する。出典を示せない数字は書かない。費用は幅のある目安として書き、断定しない。実在の施工事例・お客様の声を作り話で書かない。
7. 記事末尾に対応エリアとして「袖ヶ浦市・木更津市・君津市・富津市」の4市を併記し、CTAはメール info@ishizenkensetsu.com へ誘導(★電話番号は載せない)。excerptを100〜120字で付ける。
8. ★スラッグ(URL)は必ず英語で設定する。形式=「市名ローマ字-内容キーワード英語2〜3語」をハイフン区切りの小文字で(例: kisarazu-roof-reform, futtsu-typhoon-check)。日本語スラッグは禁止。payloadに "slug" を必ず含める。
9. 投稿は Python3 で status="draft" で POST し、戻り値の id を保持する(認証ヘッダーは付けない):
```python
import json, urllib.request
URL="https://ishizenkensetsu.com/wp-json/wp/v2/posts"
payload={"title":TITLE,"content":CONTENT_HTML,"excerpt":EXCERPT,"slug":SLUG,"status":"draft"}
req=urllib.request.Request(URL,data=json.dumps(payload).encode(),method="POST")
req.add_header("Content-Type","application/json")
b=json.loads(urllib.request.urlopen(req).read().decode())
print("ID:",b["id"],"STATUS:",b["status"],"SLUG:",b["slug"])
```
POST 後、各記事の status が draft であることを確認する。
